1. Go to developer.spotify.com/dashboard and log in with a Spotify Premium account (the app's owner needs Premium to use it).
  2. Choose Create app. Give it any name and description. For Redirect URI add exactly: {{ steps_redirect }} and tick Web API and Web Playback SDK as the APIs you plan to use. Save.
  3. Open your new app and go to Settings. The Client ID is shown there; choose View client secret to see the secret. Copy both into the boxes here.
  4. The app starts in "Development Mode": only people you add under User Management in its settings (their Spotify email, up to 5) can connect their Spotify to it.
